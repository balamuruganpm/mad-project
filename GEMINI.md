# Megawin QMS - Project Rules & Guidelines

## Core Principles
1. **Corporate Enterprise Design**: Deep Navy Blue and Slate Grey color palettes, sharper rounded corners (8px-12px) for a professional look, responsive UI, and clean data tables.
2. **PHP 8.3 OOP & MVC**: Clean Controller-Model-View separation, PDO for database execution, dynamic templates using JSON fields.
3. **Robust Security**: Strict input validation, CSRF verification, prepared statements, secure document uploads, audit tracking.
4. **No Placeholders**: Ensure all generated pages, reports, and UI elements are fully functional.

## Development Stack
- **Backend**: PHP 8.3, MVC Architecture, PDO.
- **Frontend**: HTML5, Bootstrap 5, ES6 Javascript, Material 3 Custom CSS.
- **Database**: MySQL 8.
