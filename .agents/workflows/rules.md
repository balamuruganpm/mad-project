# Project Technology Stack & Architecture

- **Backend**: PHP 8.3 + MVC + PDO
- **Frontend**: Bootstrap 5 + ES6 + Custom Material 3 Styling CSS
- **Database**: MySQL 8.0
- **Primary Domain**: Megawin Switch Gear Pvt Ltd Quality Management System (QMS)
- **Key Design Tokens**: Material 3 UI Guidelines (harmonized colors, rounded corners, responsive layout cards, interactive lists, micro-animations)
